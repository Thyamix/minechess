# MineChess

⚠️ **Warning:** This project is incomplete.  

A chess game built in Java using the [Minestom](https://github.com/Minestom/Minestom) framework.  
The core functionality works, but some move validation rules (especially discovered attacks) still need refinement.  

## Features
- Chess gameplay inside a Minestom server  
- Basic move validation  
- Turn-based play between two players  
- Partial detection of check and checkmate  

## Known Issues
- Discovered check/attack validation is incomplete  
- Some legal moves may be flagged incorrectly  

## Status
Work-in-progress.  
The project is functional for casual play, but not fully rules-compliant yet.  
Currently inactive — no further development is planned at this time.  

## Future Plans
- Fix discovered check/attack validation  
- Full support for castling, en passant, and promotion  
- Better integration with Minestom features (e.g. UI, events)  
- Potential AI or bot opponent
